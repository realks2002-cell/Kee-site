# FEATURES — 기능 명세

## Phase 1: 기반 시스템 (12주, 8개 기능)

### F01. 인터랙티브 가계도

**경로**: `/persons/[id]/tree`, `/branches/[branchId]/tree`

**난이도**: ★★★★ (가장 큰 변수)

**핵심 요구사항**:
- 본인 중심 5세대 시각화 (고조 → 자녀)
- 양자관계 점선 + 호박색 박스 표시
- 분파 단위 진입 (전체 42,924명 한 번에 X)
- [선조] [후손] 확장 버튼

**구현**:

```
데스크톱 (Week 4):
- D3.js 또는 react-d3-tree 검토
- 자체 SVG 구현 가능성 (양자관계 처리 위해)
- 줌·드래그·검색 결합

모바일 (Week 5):
- 카드 스택형 (검증된 오픈소스 없음 → 자체 구현)
- 위 스와이프 = 부모, 아래 = 자녀, 좌우 = 형제
- 본인 카드 강조 (다크 박스)
```

**RPC 함수**: `get_direct_lineage(target_person_id, ancestors_levels, descendants_levels)`

**프로토타입 우선**: Week 1에 100노드 + 양자 1개로 검증.

### F02. 인물 검색 + 상세 페이지

**경로**: `/search`, `/persons/[id]`

**난이도**: ★★★

**검색 필드**:
```
- 이름 (한글 또는 한자)
- 부친 이름 (동명이인 보조)
- 자(字) / 호(號) / 시호 / 군호 / 왕호
- 관직 / 경력
- 배우자 이름
- 분파 / 세대 필터
```

**검색 결과 표시**:
```
| 이름(한자) | 부친 | 조부 | 증조부 | 세 | 분파 |
| 성도(成度) | 우봉 | 춘연 | 광국  | 27세 | 낭장공 |
```

**인물 상세 페이지 구조**:
```
[상단] 5세대 직계 (텍스트형, 가로 정렬)
  23세 고조 - 24세 증조 - 25세 조부 - 26세 부 - 27세 본인
  
[좌] 개인자료
  본인 / 자(字) / 호 / 경력 / 묘소 / 배우자 / 자녀
  
[우] 사진자료 (4매 슬롯)
  본인 · 배우자 · 가족 · 묘소
  
[하] 족보 원문 (한문)
[하] 족보 번역 (한글)
```

**RPC**: `search_persons(...)` (DATABASE.md 참조)

### F05. 신규 등록 (수단)

**경로**: `/sudan/new`

**난이도**: ★★★ (워크플로우 복잡)

**5단계 마법사**:

**Step 1: 본인 확인** (NICE 대신 위원회 검증)
```
회원가입 (이메일/휴대폰)
↓
이름·생년월일·부친 이름 입력
↓
"위원회 인증 대기" 상태
```

**Step 2: 가지 찾기**
```
부친 이름 검색 → 추천 결과
선택 시 "본인 위치" 자동 추정
```

**Step 3: 본인 정보 입력**
```
- 한자명 (자동 추천)
- 자(字) / 호(號)
- 생년월일 (양/음력)
- 직업 (선택)
- 배우자 정보 (1조, 2조, 3조)
- 자녀 정보 (추가 가능)
```

**Step 4: 사진 업로드 (4매)**
```
- 본인 (반명함/여권)
- 배우자 (반명함/여권)
- 묘소 또는 가족 (2매)

자동 리사이즈:
  반명함: 100KB 이하
  묘소: 300KB 이하
```

**Step 5: 수단비 결제 안내**
```
입금 정보:
- 수단비: 1인당 ●●원
- 입금 계좌: 농협 351-0833-9286-23
- 입금자명: "성도2410" (자동 생성 코드)

[입금 안내 문자 받기]
```

**완료 후**:
```
"신청이 접수되었습니다.
  입금 확인 후 위원회 검토를 거쳐 승인됩니다.
  진행 상황은 마이페이지에서 확인하실 수 있습니다."
```

[ 사진 4매 ]

[승인] [보완 요청] [반려]

**audit log 자동 기록**:
- 누가 (`changed_by`)
- 언제 (`created_at`)
- 무엇을 (`field_name`, `old_value`, `new_value`)
- 왜 (`reason`)
- 어떤 신청으로 (`application_id`)

### F09. AI 조상 발견 (온보딩)

**난이도**: ★★

**플로우**:
```
청년 첫 가입 5분:
1. 본인 이름 + 생년 + 부친 이름 입력
2. AI가 가계도에서 위치 자동 탐색
3. "당신은 ●●공의 9대손" 발표
4. 가장 유명한 조상 1명 카드로 소개
   - 등급 ★★★★★
   - 관직, 업적, 본인과의 관계
5. "내 가계도 전체 보기" CTA
```

**유명 조상 선정 기준**:
- 시호(諡號) 보유
- 군호(君號) 보유
- 정승급 관직 (영의정, 좌의정, 우의정)
- 학자·의병장 등 역사적 인물
- → `persons.notable_score` 컬럼 도입 (위원회 큐레이션)

### F12. 동년배 종친 찾기

**난이도**: ★★

**기능**:
```
같은 세대(예: 31세) 종친:
- 전국 인원수 (874명)
- 분파별 분포 (점 그래프)
- 시·도별 분포 (지역 단위만 공개)

비슷한 연령대:
- ±10세 자동 그룹

같은 지역 종친:
- 시·구 단위만 공개 (개인정보 보호)
```

**금지 사항** (어르신 정서 존중):
- ❌ 직접 메시지 X
- ❌ 1:1 매칭 X
- ❌ 휴대폰 번호 공개 X
- ✓ 행사 참여 알림만 ("31세 종친 23명 참석 예정")
